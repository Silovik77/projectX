# Лесной забег - Перенос web-игры на Godot

## Обзор проекта

Это проект по переносу браузерной игры "Лесной забег" (раннер с тремя полосами) на движок Godot 4.3.

## Структура проекта

```
godot_project/
├── project.godot          # Основной файл проекта Godot
├── scenes/                # Сцены (.tscn файлы)
│   └── main.tscn         # Главная сцена игры
├── scripts/              # Скрипты GDScript
│   ├── game_manager.gd   # Глобальный менеджер игры
│   ├── player.gd         # Контроллер игрока
│   ├── track_manager.gd  # Генерация и управление трассой
│   ├── audio_manager.gd  # Управление звуками
│   └── ui_manager.gd     # Управление интерфейсом
├── assets/               # Графические ресурсы
│   ├── *.png            # Спрайты персонажей и объектов
│   └── ...
└── sounds/              # Звуковые файлы
```

## Основные механики (из оригинальной игры)

### Геймплей
- **Три полосы движения** (-2.4, 0, 2.4 по оси X)
- **Бесконечный раннер** - игрок бежит автоматически
- **Препятствия**: пни и бревна (нужно перепрыгивать)
- **Монеты** (яблоки) - собираются для валюты
- **Бонусы**:
  - 🧲 Магнит - притягивает монеты
  - ✖️ x2 - удваивает монеты
  - 🚀 Ракета - неуязвимость и ускорение

### Управление
- **Стрелки влево/вправо** или **A/D** - смена полосы
- **Стрелка вверх**, **W** или **Пробел** - прыжок
- **Esc** - пауза
- **Свайпы** (для touch устройств)

### Прогрессия
- Скорость увеличивается каждые 1000 метров
- Сложность растет с дистанцией
- Сохранение рекордов и монет

### Персонажи
- 🦊 Лисёнок (стартовый)
- 🐰 Заяц (100 яблок)
- 🦔 Ёжик (150 яблок)
- 🐿️ Белка (200 яблок)

## Архитектура кода

### GameManager (scripts/game_manager.gd)
- Синглтон для глобального состояния
- Управление прогрессом (монеты, рекорды)
- Система эффектов (магнит, x2, ракета)
- Сохранение/загрузка данных

### Player (scripts/player.gd)
- Физика прыжков и гравитация
- Плавное перемещение между полосами
- Анимация бега и прыжков
- Обработка столкновений

### TrackManager (scripts/track_manager.gd)
- Процедурная генерация препятствий
- Паттерны спавна (как в оригинале)
- Обновление позиций объектов
- Очистка за экраном

### UIManager (scripts/ui_manager.gd)
- Переключение экранов (меню, магазин, пауза, результаты)
- Отображение HUD (монеты, дистанция)
- Магазин персонажей
- Таблица рекордов

### AudioManager (scripts/audio_manager.gd)
- Воспроизведение звуковых эффектов
- Управление громкостью
- Кэширование звуков

## Отличия от оригинала

### Технические
- **2.5D вместо 3D** - используем 2D спрайты с перспективой
- **Godot Physics** вместо Three.js
- **GDScript** вместо JavaScript
- **Локальное сохранение** вместо Yandex SDK

### Визуальные
- Спрайтовая анимация вместо 3D моделей
- Параллакс фон для эффекта глубины
- Particles для эффектов (монеты, бонусы)

## Установка и запуск

1. Установите Godot 4.3+
2. Откройте `project.godot`
3. Нажмите F5 для запуска

## Требования к ресурсам

### Необходимые спрайты
- Персонажи: fox, bunny, hedgehog, squirrel (side view + run cycles)
- Препятствия: stump, log
- Монеты: apple
- Бонусы: magnet, x2, rocket
- Фон: forest background

### Звуки
- jump.wav - прыжок
- coin.wav - сбор монеты
- powerup.wav - активация бонуса
- land.wav - приземление
- stumble.wav - столкновение
- collect.wav - покупка
