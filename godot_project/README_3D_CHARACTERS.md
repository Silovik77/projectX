# Руководство по 3D персонажам и обновлённой физике

## Что было сделано

### 1. **Новый 3D скрипт игрока (`player_3d.gd`)**
Создан полноценный скрипт для 3D персонажа с расширенной физикой:

#### ✅ **Физические улучшения:**
- **Вертикальная физика прыжков** - гравитация, скорость падения, определение приземления
- **Инерция при смене полос** - плавное перемещение с ускорением и замедлением
- **Динамический наклон корпуса** - персонаж наклоняется в сторону движения (до ±15°)
- **Наклон вперёд при беге** - естественная поза бегущего персонажа
- **Определение состояния "на земле"** - точное отслеживание контакта с поверхностью

#### ✅ **Система анимаций:**
- **Автоматическая загрузка 3D моделей** - поддержка форматов .glb/.gltf
- **AnimationTree интеграция** - blend space для плавных переходов между анимациями
- **Параметры состояний**:
  - `jump` / `grounded` - переключение бег/прыжок
  - `stagger` - анимация спотыкания
  - `Run/blend_position` - скорость бега
- **Процедурная анимация** - расчёт фазы бега на основе скорости игры

#### ✅ **Персонажи:**
Поддержка 4 персонажей с автоматической загрузкой моделей:
- 🦊 **Лиса** (fox.glb) - по умолчанию
- 🐰 **Заяц** (bunny.glb)
- 🦔 **Ёжик** (hedgehog.glb)
- 🐿️ **Белка** (squirrel.glb)

Если модель не найдена - создаётся оранжевая капсула-заглушка.

## 🎮 Как настроить сцену в Godot

### Шаг 1: Создайте сцену игрока

1. Откройте Godot Editor
2. Создайте новую сцену → **3D Scene**
3. Добавьте узлы:
   ```
   CharacterBody3D (имя: Player)
   ├── CollisionShape3D
   ├── Model (Node3D)
   │   └── [сюда загрузится модель]
   └── Script (прикрепите player_3d.gd)
   ```

### Шаг 2: Настройте CollisionShape3D

- Тип: **CapsuleShape3D**
- Radius: `0.4`
- Height: `1.0`

### Шаг 3: Экспортные переменные в инспекторе

ВInspector выберите Player и настройте:
- **Pet Type**: имя персонажа ("fox", "bunny", "hedgehog", "squirrel")
- **Lane**: стартовая полоса (0, 1, 2)
- **Gravity**: `25.0` (можно менять для разных ощущений)
- **Jump Velocity**: `8.0`
- **Move Speed**: `6.0`
- **Lane Change Smoothness**: `8.0` (плавность смены полос)
- **Rotation Smoothness**: `12.0` (плавность наклонов)

## 🏃‍♂️ Продвинутые возможности физики

### Динамический наклон при движении
```gdscript
var tilt_angle = -lateral_velocity * 0.15
model.rotation.z = lerp(model.rotation.z, tilt_angle, delta * rotation_smoothness)
```
Персонаж наклоняется влево/вправо при смене полосы, создавая эффект инерции.

### Реалистичные прыжки
```gdscript
vertical_velocity -= gravity * delta
position.y += vertical_velocity * delta
```
Классическая физика с ускорением свободного падения.

### Эффект спотыкания
```gdscript
func stagger(duration: float = 0.3) -> void:
    var backward_impulse = Vector3(0, 0, 1.5)
    position += backward_impulse
    # Запуск анимации спотыкания
```

## 🎨 Требования к 3D моделям

Для корректной работы анимаций модели должны содержать:

### Обязательная структура:
```
Model_Root
├── Mesh (скелетная геометрия)
├── Skeleton3D
├── AnimationPlayer
│   ├── run (циклическая анимация бега)
│   ├── jump (анимация прыжка)
│   ├── land (анимация приземления)
│   └── stagger (анимация спотыкания)
└── AnimationTree (опционально, можно добавить в коде)
```

### Рекомендуемые параметры:
- **Единицы измерения**: 1 unit = 1 метр
- **Высота персонажа**: ~1.0-1.2 метра
- **Количество костей**: < 50 для мобильной оптимизации
- **Текстуры**: 512x512 или 1024x1024 (формат PNG)

### Blend Space настройки (в AnimationTree):
Создайте **BlendSpace2D** с параметрами:
- **X-axis**: speed (0-10)
- **Y-axis**: direction (-1 to 1)
- Точки:
  - (0, 0) → idle
  - (5, 0) → walk
  - (10, 0) → run
  - (0, 1) → jump_start
  - (0, -1) → land

## 🔧 Сравнение 2D vs 3D версии

| Параметр | 2D версия | 3D версия |
|----------|-----------|-----------|
| **Движение** | Линейное, без инерции | Плавное с ускорением/замедлением |
| **Прыжки** | Простая вертикаль | Физика с гравитацией |
| **Анимации** | Спрайты (2 кадра) | Скелетные (blend space) |
| **Наклоны** | Нет | Динамические (X, Z оси) |
| **Модели** | PNG спрайты | GLB/GLTF 3D модели |
| **Коллизии** | Rectangle2D | CapsuleShape3D |
| **Камера** | Статичная 2D | Перспектива 3D |
